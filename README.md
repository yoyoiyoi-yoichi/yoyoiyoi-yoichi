# Hi, I'm Meiko 👋

### Embedded & IoT Engineer · Tokyo

I wire industrial sensors to the cloud over MQTT — and get called when they stop talking.

Most of my bugs turn out to be expired certificates, dead switches, or unplugged gateways. The rest I chase through serial logs and packet captures.

**Toolbox:** MQTT (Mosquitto / EMQX / AWS IoT Core), ESP32, Raspberry Pi, Modbus, BLE, Python, Wireshark.

The lab calls me the gorilla: I carry the UPS, rack the servers, and debug the broker ACL afterwards. Pink bob and dark glasses, so the field techs can find me in a warehouse.

Work rule: measure first, log everything, change one thing at a time.

— Meiko
